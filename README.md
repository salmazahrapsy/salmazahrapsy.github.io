# salmazahrapsy.github.io

Personal portfolio of **Salma Zahra** — Psychology undergraduate from Indonesia working on psychology, psychological statistics, research and emerging technology.

Live site: https://salmazahrapsy.github.io/

## Structure

| Path | Page |
| --- | --- |
| `/` | Home |
| `/about/` | About and contact |
| `/research/` | Research questions, claim labels, ethics |
| `/projects/` | Project index |
| `/psychstats/` | PsychStats |
| `/psyweb3/` | PsyWeb3 (separate repo `salmazahrapsy/psyweb3`) |
| `/business-behaviour/` | Case study: emotion in Indonesian product reviews |
| `/gmp-2027/` and `/gmp-2027/timeline/` | GMP 2027 preparation (public, non-confidential) |

Pages are generated by `tools/build_site.py` (Python standard library only) with one stylesheet, `assets/site.css`. Edit the text in `tools/build_site.py` and commit: GitHub Actions rebuilds and redeploys automatically.

## Publishing

Settings → Pages → Source: **GitHub Actions** (`.github/workflows/pages.yml`).

## Checks

The deploy workflow also checks links on every push.

## Rules for this repository

- Every factual claim must be checkable. No invented numbers, users or results.
- Never commit application answers, passport details, private email, tokens or API keys.
- The official GMP application is submitted only through Fast Retailing's portal.
